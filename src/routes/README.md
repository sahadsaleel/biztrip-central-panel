# Routes

TanStack Router uses **file-based routing**. Every `.tsx` file in this directory
defines a route. The root layout is `src/routes/__root.tsx`.

## Conventions

| File                | URL                                            |
| ------------------- | ---------------------------------------------- |
| `index.tsx`         | `/`                                            |
| `trips.tsx`         | `/trips`                                       |
| `enquiries.tsx`     | `/enquiries`                                   |
| `invoicing.tsx`     | `/invoicing`                                   |
| `accounts.tsx`      | `/accounts`                                    |
| `fleet.tsx`         | `/fleet`                                       |
| `activity.tsx`      | `/activity`                                    |
| `reports.tsx`       | `/reports`                                     |
| `notifications.tsx` | `/notifications`                               |
| `settings.tsx`      | `/settings`                                    |
| `users.tsx`         | `/users`                                       |
| `__root.tsx`        | app shell — wraps every page with `<Outlet />` |

`routeTree.gen.ts` is auto-generated by `@tanstack/router-plugin`.
